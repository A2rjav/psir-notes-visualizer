Bhikhu Parekh is optimistic and he believes that
some common values can emerge through dialogue
which can be applicable at cosmopolitan level.
He believes that Human Dignity is one such prin-
ciple where we can develope common values.

Bhikhu Parekh proposes the application of Harm
principle. If there is no concrete harm to anyone
with respect to any cultural specific practice
such practices need not to be restricted. Harm
principle can achieve the balance between Auto-
nomy & culture.

• Short Note on Value Pluralism-
value pluralism as a concept is given by Isaib Berlin
Context of value pluralism-
It is in context of the debate between values.
Eg. The debate between Liberty & Equality.
value Pluralism VS value Monism -
According to Isaib Berlin, value Monism means one
value determining all choices. Eg. Utilitarians take
utility as the ultimate determinant for all actions.
According to I. Berlin, peoples have different values. If
someone believes that Liberty has a priority over equa-
lity no no. of arguements will convince the person that
equality has a priority. Hence, one should not prioritise
values. Eg. In liberal countries primacy is given to liberty
According to I. Berlin, there can be many such values
which are equally correct and yet in conflict with each
other Eg. Liberty & Equality. Problem increased further
because values are "incommensurable" (cannot be
measured) and prioritised.
