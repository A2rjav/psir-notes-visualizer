According to Lenin, Historical Materialism suggest that
economic structure is the basic structure.
State is a part of superstructure.
In all stages of History there have been two classes i.e.
owners & Non-owners. Owners are the exploiter & non-
owners are exploited.

There can never be a reconciliation between the interest
of exploiter & exploited.
The presence of state itself shows that class antagonism
cannot be resolved.
State is an instrument created by Bourgeoise class. State
uses force on the poors in the interest of the Bourgeoise
class. Poors cannot expect justice from the state. Hence,
the only option is revolution. So long classes exists, class
struggle exist & so long class struggle exists state exists.

In communism classes end so class struggle ends. Hence
state withers away.

③ __conclusion__
Above discription of state is from Marxist perspective.
Whether state represent irreconcilability or not remains
a matter of debate.
